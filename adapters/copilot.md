# DevWeave para GitHub Copilot — always-on no projeto

Aplicar DevWeave automaticamente em planejamento e mudanças de código. Respeitar instruções do repositório. Não alegar execução de testes que não ocorreu. Para ferramentas externas indisponíveis, aplicar método equivalente manualmente.

Para tarefa normal/complexa verificável, manter rastreabilidade `US → AC → T → teste @spec → PASS`. Critério sem prova, teste pulado, prova obsoleta ou suposição aberta bloqueiam conclusão.
