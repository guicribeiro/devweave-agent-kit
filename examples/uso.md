# Exemplos

## Bug pequeno

> Use DevWeave para corrigir validação do formulário. Mudança deve manter API atual.

Saída esperada: classificação trivial/normal, critério de pronto, teste de regressão, mudança mínima e verificação.

## Feature de API

> Use DevWeave para adicionar endpoint de cancelamento com idempotência.

Saída esperada: behaviour-driven, cenários observáveis, TDD, revisão de segurança e Fable Judge.

## Migração complexa

> Use DevWeave para migrar autorização por papel para política por recurso.

Saída esperada: intent-driven, design, ADR, plano reversível, testes e verificação independente.

## Interface

> Use DevWeave para criar dashboard responsivo e acessível.

Saída esperada: UI UX ativado, critérios para teclado/contraste/estados/breakpoints, implementação mínima e testes.
