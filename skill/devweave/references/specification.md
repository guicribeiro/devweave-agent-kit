# Especificação proporcional

## Minimalist

Usar para correção pequena ou componente isolado.

Produzir:

- intenção;
- escopo e fora de escopo;
- critérios de aceitação;
- checks.

## Behaviour-driven

Usar para API, CRUD, formulário, integração ou regra de negócio.

Produzir:

- atores e comportamento;
- cenários Given/When/Then;
- erros e limites;
- tarefas;
- testes correspondentes.

## Intent-driven

Usar para arquitetura, auth, dados, segurança, migração ou decisão difícil de reverter.

Produzir:

- proposal;
- specs;
- design;
- ADR;
- plano de migração/reversão;
- tarefas e gates.

Artefatos devem reduzir risco. Não criar documentação cerimonial sem uso na implementação.
